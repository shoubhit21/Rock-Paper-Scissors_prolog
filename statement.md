# Project Statement – Rock Paper Scissors in Prolog

## What is this project?

This is a simple command‑line game where you play Rock, Paper, Scissors against your computer. The computer picks a move randomly, and the program tells you who won. You can keep playing as long as you want, and type `quit.` when you’re done.

## Why did I make this?

I built this as a small but fun way to learn two things:
- **Prolog programming** – using rules, facts, and recursion.
- **Using GitHub** – uploading code, writing a README, and sharing my work.

The game is short (less than 40 lines of code) but shows important ideas like:
- Getting input from the user.
- Making random choices.
- Handling errors (like typing something that isn’t rock, paper, or scissors).
- Looping until the user wants to stop.

## What do you need to run it?

- A computer with **SWI‑Prolog** installed.  
  (It’s free and works on Windows, Mac, and Linux.)
- No internet connection needed after you download the file.

## How to run the game

1. Open a terminal (or command prompt).
2. Navigate to the folder where `rock_paper_scissors.pl` is saved.
3. Type `swipl` to start Prolog.
4. Load the file: `[rock_paper_scissors].`
5. Start the game: `main.`
6. Follow the on‑screen prompts.

## What I learned

- How to model a simple game using Prolog’s pattern matching.
- How to generate a random number and map it to a move.
- How to make a program loop without getting stuck.
- How to write a clean README and share a project on GitHub.
