# Project Statement – Rock Paper Scissors in Prolog

## What is this project?

This is a simple command‑line game where you play Rock, Paper, Scissors against the computer. The computer picks a move randomly from rock,paper & scissors, and the program tells you who won. You can keep playing as long as you want, and type `quit.` when you’re done.

## Why did I create this?

#### I made this to learn two things in a fun way:
- **Prolog programming**. I used it to make rules, logic and recursion work.
- **Using GitHub**. I learned to upload my code write a README and share it with others
#### This game is short. It shows some key ideas:
- Getting things from the user.
- Letting the computer make random choices.
- Fixing errors like if the user types something weird.
- Keeping things going until the user wants to stop.

## What do you need to run it?

- A computer with **SWI‑Prolog** installed.  
- No internet connection needed after you download the file.

## How to run the game

1. Open a terminal (or command prompt).
2. Navigate to the folder where `rock_paper_scissors.pl` or `main.pl`(as per my repository) is saved.
3. Type `swipl` to start Prolog.
4. Load the file: `[rock_paper_scissors].`
5. Start the game: `main.`
6. Follow the on‑screen instructions.
